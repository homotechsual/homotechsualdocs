## SYNOPSIS

Updates the order of custom tabs globally.

## SYNTAX

```powershell
Set-NinjaOneTabGlobalOrder [-order] <Object> [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION

Updates the order of globally available custom tabs via the NinjaOne v2 API.

## EXAMPLES

### EXAMPLE 1

```powershell
Set-NinjaOneTabGlobalOrder -order @(
    @{ tabId = 1; order = 1 },
    @{ tabId = 2; order = 2 }
)
```


Sets the global tabs order.
