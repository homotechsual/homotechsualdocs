## SYNOPSIS

Updates end user device access.

## SYNTAX

```powershell
Set-NinjaOneEndUserDeviceAccess [-id] <Int32> [[-addDeviceIds] <Int32[]>] [[-removeDeviceIds] <Int32[]>]
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Updates the set of devices an end user can access using the NinjaOne v2 API.

## EXAMPLES

### EXAMPLE 1

```powershell
Set-NinjaOneEndUserDeviceAccess -Id 101 -addDeviceIds 10, 11 -removeDeviceIds 12
```


Adds devices 10 and 11 and removes device 12 from end user 101 access.
