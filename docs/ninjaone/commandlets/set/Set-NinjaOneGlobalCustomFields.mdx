## SYNOPSIS

Updates global custom field values.

## SYNTAX

```powershell
Set-NinjaOneGlobalCustomFields [-globalCustomFields] <Object> [-ProgressAction <ActionPreference>] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Updates system-wide custom field values using the NinjaOne v2 API.

## EXAMPLES

### EXAMPLE 1

```powershell
Set-NinjaOneGlobalCustomFields -globalCustomFields @{ region = 'Europe' }
```


Updates the global region custom field value.
