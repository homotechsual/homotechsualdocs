## SYNOPSIS

Updates organization permissions for a user role.

## SYNTAX

```powershell
Set-NinjaOneUserRoleOrganizationPermissions [-roleId] <Int32> [-permissions] <Object>
 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION

Updates organization permissions for the specified user role via the NinjaOne v2 API.

## EXAMPLES

### EXAMPLE 1

```powershell
Set-NinjaOneUserRoleOrganizationPermissions -roleId 10 -permissions @{ allowAll = $true }
```


Updates organization permissions for role 10.
