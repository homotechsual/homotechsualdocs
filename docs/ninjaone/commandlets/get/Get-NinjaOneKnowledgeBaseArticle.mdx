## SYNOPSIS

Gets a knowledge base article from the NinjaOne API.

## SYNTAX

### Download (Default)

```powershell
Get-NinjaOneKnowledgeBaseArticle [-articleId] <Int32> [-signedUrls] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

### Details

```powershell
Get-NinjaOneKnowledgeBaseArticle [-articleId] <Int32> [-details] [-ProgressAction <ActionPreference>]
 [<CommonParameters>]
```

## DESCRIPTION

Downloads a knowledge base article from the NinjaOne v2 API by default.
Use -details to retrieve the article object or -signedUrls to retrieve signed URLs.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-NinjaOneKnowledgeBaseArticle -articleId 1
```


Gets the knowledge base article with id 1.

### EXAMPLE 2

```powershell
Get-NinjaOneKnowledgeBaseArticle -articleId 1 -details
```


Gets the article object for the knowledge base article with id 1.
