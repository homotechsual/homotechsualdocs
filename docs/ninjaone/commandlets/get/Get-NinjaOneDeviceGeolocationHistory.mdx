## SYNOPSIS

Gets geolocation history for a mobile device.

## SYNTAX

```powershell
Get-NinjaOneDeviceGeolocationHistory [-deviceId] <Int32> [-after <Double>] [-before <Double>]
 [-pageSize <Int32>] [-cursor <String>] [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION

Retrieves one page of mobile device geolocation history.
The API defaults to
the last seven days and the time window cannot exceed seven days.
Use the returned cursor to retrieve subsequent pages.

## EXAMPLES

### EXAMPLE 1

```powershell
Get-NinjaOneDeviceGeolocationHistory -deviceId 1 -pageSize 100
```


Gets the first page of geolocation history for device 1.

### EXAMPLE 2

```powershell
Get-NinjaOneDeviceGeolocationHistory -deviceId 1 -after 1791244800 -before 1791849600 -cursor 'next-page'
```


Gets a subsequent page within the specified epoch-second time window.
