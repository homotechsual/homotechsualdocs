## SYNOPSIS
Deletes a print job.

## SYNTAX

```powershell

 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Deletes a print job.
Uses the documented Printix Cloud Print API.
Required application type: Cloud Print API or Card registration (API terminology).
