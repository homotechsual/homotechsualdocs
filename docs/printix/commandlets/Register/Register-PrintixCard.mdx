## SYNOPSIS
Registers a converted, base64-encoded card number for a user.

## SYNTAX

```powershell

 [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm] [<CommonParameters>]
```

Uses the documented Printix Cloud Print API.
