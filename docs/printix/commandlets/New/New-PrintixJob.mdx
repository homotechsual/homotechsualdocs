## SYNOPSIS
Creates a print job using either documented submission version.

## SYNTAX

### Modern (Default)
```powershell
New-PrintixJob [-TenantId <String>] -PrinterId <String> -QueueId <String> -Title <String> [-User <String>]
 [-PDL <String>] [-ReleaseImmediately <Boolean>] [-Color <Boolean>] [-Duplex <String>]
 [-PageOrientation <String>] [-Copies <Int32>] [-MediaSize <String>] [-Scaling <String>]
 [-UserMappingKey <String>] [-UserMappingValue <String>] [-ProgressAction <ActionPreference>] [-WhatIf]
 [-Confirm] [<CommonParameters>]
```

### Legacy
```powershell
New-PrintixJob [-TenantId <String>] -PrinterId <String> -QueueId <String> -Title <String> [-User <String>]
 [-PDL <String>] -LegacyTicket <Hashtable> [-ProgressAction <ActionPreference>] [-WhatIf] [-Confirm]
 [<CommonParameters>]
```

## DESCRIPTION
Returns the complete submission response, including uploadLinks and uploadCompleted.
Creation alone does not upload or print a document.
Version 1.1 is the default.
Required application type: Cloud Print API or Card registration (API terminology).
Requires Printix Premium.

## EXAMPLES

### EXAMPLE 1
```powershell
New-PrintixJob -PrinterId $printerId -QueueId $queueId -Title 'Monthly report' -Duplex LONG_EDGE -ReleaseImmediately $false
```

### EXAMPLE 2
```powershell
New-PrintixJob -PrinterId $printerId -QueueId $queueId -Title 'Legacy document' -LegacyTicket $ticket
```
