## SYNOPSIS
Creates a normal or guest user.

## SYNTAX

```powershell
New-PrintixUser [[-TenantId] <String>] [-Email] <String> [-FullName] <String> [-Role] <String>
 [[-Pin] <SecureString>] [[-Password] <SecureString>] [[-ExpirationTimestamp] <String>]
 [[-SendWelcomeEmail] <Boolean>] [[-SendExpirationEmail] <Boolean>] [-Raw] [-ProgressAction <ActionPreference>]
 [-WhatIf] [-Confirm] [<CommonParameters>]
```

## DESCRIPTION
Creates a normal or guest user.
Uses the documented Printix Cloud Print API.
Required application type: User manager for role USER; User manager, Cloud Print API,
or Card registration (API terminology) for role GUEST_USER.
Requires Printix Premium.

## EXAMPLES

### EXAMPLE 1
```powershell
New-PrintixUser -TenantId $tenantId -Email $email -FullName $fullName -Role $role
```
