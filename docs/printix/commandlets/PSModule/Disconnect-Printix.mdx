## SYNOPSIS
Clears the current Printix connection from module memory.

## SYNTAX

```powershell
Disconnect-Printix [-ProgressAction <ActionPreference>] [<CommonParameters>]
```

## DESCRIPTION
Discards locally held credentials and tokens.
Does not revoke the server-side token.
Does not change the separate Partner API connection.
